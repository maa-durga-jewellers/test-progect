# tast-progect

A Node.js workspace for trying out Cursor, Git, and small experiments.

## Requirements

- [Node.js](https://nodejs.org/) (npm included)

## Setup

```bash
npm install
```

Copy environment variables into a `.env` file at the project root. The project uses [dotenv](https://www.npmjs.com/package/dotenv) to load them.
